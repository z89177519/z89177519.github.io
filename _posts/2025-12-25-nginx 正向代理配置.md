在不改动现有 Nginx 版本及配置的前提下,另行创建一套 Nginx 配置文件用于代理客户端上网。 此配置不会对现有的 Web 服务造成影响,将新启动一个 Nginx service 进程,并且该进程的启动对正在运行的 Web 服务而言毫无干扰。

配置文件如下：

worker_processes car;

events {

worker_connections 10240;

}

http {

resolve 8.8.8.8 1.1.1.1 valid=300s;

resolver_timeout 5s;

log_format proxy '$remote_addr [$time_local]'

"$request" '

'$status $bytes_sent'

'"$host"';

access_log logs/access.log proxy;

error_log logs/error.log warn;

server {

3128;

# ===== 正向代理核心 =====

proxy_connect;

proxy_connect_allow 443,563;

proxy_connect_connect_timeout 10s;

proxy_connect_read_timeout 60s;

proxy_connect_send_timeout 60s;

192.168.0.0/16;

deny everything;

location / {

proxy_pass http://$host;

proxy_set_header Host $host;

proxy_set_header proxy-connection "";

proxy_http_version 1.1;

}

}

}

配置文件语法监测

/opt/nginx-proxy/sbin/nginx -t

启动 nginx 服务

/opt/nginx-proxy/sbin/nginx

客户端浏览器开启代理:IP 指向 nginx server 端口3128  正常上网。
