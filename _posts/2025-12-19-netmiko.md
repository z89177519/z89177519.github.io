Netmiko是什么？
Netmiko 通过提供统一的界面来管理来自不同厂商的设备，从而简化了对网络设备的 SSH 管理。其主要用途包括：

建立与设备的 SSH 连接

执行、检索和格式化 show 命令

发送配置命令

安装 Netmiko 
Netmiko 不是 Python 标准库的一部分，因此您需要使用 Python 库进行安装pip。在所有操作系统（例如 macOS/Linux）上的安装过程都类似。要安装 Netmiko，请使用pip以下方法：

pip install netmiko
Netmiko 有几个依赖项，pip 会自动为您安装，包括Paramiko、scp、pyserial和textfsm。

为了确保 Netmiko 已正确安装，您可以通过在 Python shell 中导入它来进行测试。

连接单个设备
要使用 Netmiko 建立与设备的 SSH 连接，请导入该类ConnectHandler并提供必要的设备详细信息：

from netmiko import ConnectHandler

connection = ConnectHandler(
    host="172.16.10.12", username="admin", password="cisco", device_type="cisco_ios"
)
output = connection.send_command("show ip interface brief")
print(output)
connection.disconnect()

使用 Netmiko 中的 Python 字典简化设备连接
为了保持设备清单的有序性和易用性，Python 字典提供了一种高效的解决方案。假设我们有一台 Cisco 设备，其详细信息包括：运行 iOS 系统、IP 地址以及用于访问该设备的用户名和密码。

我们可以将所有这些细节整齐地打包到一个名为 `Python 字典` 的文件中SW_01：

SW_01 = {
    "device_type": "cisco_ios",
    "host": "172.16.10.12",
    "username": "admin",
    "password": "cisco"
}
现在，当我们想使用 Netmiko 连接到此设备时，只需解压此字典即可：

from netmiko import ConnectHandler

# Unpacking the dictionary to connect to the device
connection = ConnectHandler(**SW_01)
我们已经使用字典中存储的凭据建立了与设备的连接。接下来，我们可以像往常一样向设备发送命令。让我们获取其接口的描述：

output = connection.send_command('show interface desc')
print(output)
完成后，我们可以优雅地关闭连接：

connection.disconnect()

使用 Netmiko 启用特权 EXEC 模式
在使用 Netmiko 自动化网络设备上的任务时，有时会遇到默认登录模式无法授予我们必要权限的情况。例如，尝试运行某些命令可能会导致错误。show run

为了解决这个问题，Netmiko 提供了一种方案：启用特权 EXEC 模式。此模式赋予我们更高的权限，允许我们执行更广泛的命令。让我们看看如何以简单直接的方式实现这一点。

首先，我们像之前一样，在 Python 字典中定义设备详细信息：

SW_01 = {
    "device_type": "cisco_ios",
    "host": "172.16.10.12",
    "username": "admin",
    "password": "cisco",
    "secret": "cisco123"  # Enable password
}
请注意新增的参数secret。我们在这里指定enable密码，这是进入特权执行模式所必需的。接下来，我们像往常一样建立与设备的连接：

connection = ConnectHandler(**SW_01)
现在，这个功能派上用场了！enable()Netmiko 提供的切换到特权 EXEC 模式的方法：

connection.enable()
这行简单的代码提升了我们的权限，使我们能够访问更强大的命令。要验证是否已成功切换到特权执行模式，我们可以使用以下find_prompt()方法：

device_prompt = connection.find_prompt()
print(device_prompt)
这将打印出设备的提示符，确认我们现在处于特权执行模式。现在，我们可以放心地执行诸如 `ls` 之类的命令，而不会遇到权限问题：show run

output = connection.send_command('show run')
print(output)
完成后，最好优雅地关闭连接：

connection.disconnect()
只需几行代码，我们就能通过 Netmiko 启用特权 EXEC 模式，从而释放网络自动化脚本的全部潜力。

使用 Netmiko 进行设备配置
Netmiko 提供了一种便捷的方式来进入全局配置模式，我们可以在该模式下更改设备的设置。接下来，我们将深入探讨如何使用 Netmiko 来驾驭全局配置模式的强大功能。

首先，我们像以前一样，在 Python 字典中设置设备详细信息：

SW_01 = {
    "device_type": "cisco_ios",
    "host": "172.16.10.11",
    "username": "admin",
    "password": "cisco",
    "secret": "cisco123"  # Enable password
}
然后，我们建立与设备的连接，并将权限提升到特权执行模式：

connection = ConnectHandler(**SW_01)
connection.enable()  # Enable method
现在，需要使用以下config_mode()方法进入全局配置模式：

connection.config_mode()  # Global config mode
启用全局配置模式后，我们可以在设备上执行配置命令。例如，我们来创建一个访问控制列表 (ACL) ：access-list 1 permit any

connection.send_command('access-list 1 permit any')
配置任务完成后，务必使用以下exit_config_mode()方法退出全局配置模式：

connection.exit_config_mode()  # Exit global config mode
就这样，我们无缝地切换回了特权 EXEC 模式，准备执行 show 命令或其他任务。

为了演示，我们来获取设备接口的描述：

show_output = connection.send_command('show interface desc')
print(show_output)
最后，作为最佳实践，我们优雅地关闭连接：

connection.disconnect()
借助 Netmiko 的全局配置模式，设备配置变得轻而易举。无论是创建访问控制列表 (ACL)、调整接口设置还是进行其他配置更改，Netmiko 都能让我们自信地实现自动化。

使用 Python 的 getpass 函数在网络自动化中保护密码
在网络自动化领域，安全至关重要。以明文形式存储密码或密钥是一个很大的错误。幸运的是，Python 为我们提供了一个解决方案：该getpass库getpass允许我们提示用户输入敏感信息（例如密码），而无需将他们的输入回显到终端。这意味着密码始终处于隐藏状态，从而提高了安全性。

让我们来探讨如何getpass在网络自动化脚本中安全地处理密码。

from netmiko import ConnectHandler
import getpass

passwd = getpass.getpass('Please enter the password: ')  # Prompt user for password securely

SW_01 = {
    "device_type": "cisco_ios",
    "host": "172.16.10.11",
    "username": "admin",
    "password": passwd,  # Log in password from getpass
    "secret": passwd  # Enable password from getpass
}

connection = ConnectHandler(**SW_01)
connection.enable()  # Enter Privilege EXEC mode

output = connection.send_command('show interface desc')
print(output)

connection.disconnect()
在这个脚本中，我们使用getpass交互式提示功能来提示用户输入密码。输入的密码随后会以字符串的形式安全地保存到passwd变量中。

接下来，我们定义设备详细信息，包括从[此处应填写系统名称]获取的用户名和密码getpass。然后使用这些信息建立与设备的连接。

连接成功后，我们可以根据需要对设备执行命令。在本例中，我们使用该方法获取接口的描述send_command。

最后，我们优雅地关闭与设备的连接。

通过利用该技术getpass，我们确保网络自动化脚本中的密码处理安全无虞。再也不用担心将敏感信息以明文文件形式存储了！

发送多个命令
在网络自动化领域，向单个设备发送单个命令仅仅是冰山一角。我们真正需要的是能够使用单个 Python 脚本发送多个命令，包括显示命令和配置命令。值得庆幸的是，Netmiko 凭借其强大的send_config_set方法实现了这一点。

让我们深入探讨如何利用此功能来简化我们的配置任务。

首先，让我们收集连接设备所需的必要信息，为后续步骤做好准备。我们将提示用户安全地输入密码：

from netmiko import ConnectHandler
import getpass

passwd = getpass.getpass('Please enter the password: ')

SW_01 = {
    "device_type": "cisco_ios",
    "host": "172.16.10.11",
    "username": "admin",
    "password": passwd,  # Log in password from getpass
    "secret": passwd  # Enable password from getpass
}
准备好设备详细信息后，我们建立连接并将权限提升到特权执行模式：

connection = ConnectHandler(**SW_01)
connection.enable()
现在，让我们定义一个要推送至设备的配置命令列表：

config_commands = ['interface gi0/0', 'description WAN', 'exit', 'access-list 1 permit any']
使用这种send_config_set方法，我们可以将这一系列命令发送到设备。该方法会自动进入全局配置模式，执行命令，然后退出全局配置模式：

connection.send_config_set(config_commands)
就这样，我们用一个Python脚本就向设备推送了多个配置命令。无需手动逐个输入命令。

为了验证我们的配置是否已应用，我们可以在设备上运行 show 命令：

print(connection.send_command('show interfaces description'))
print(connection.send_command('show access-lists'))
最后，在结束之前，让我们优雅地结束这次连接：

connection.disconnect()
借助 Netmiko 的send_config_set方法，设备配置变得轻而易举。无论是设置接口描述、创建访问控制列表 (ACL) 还是进行其他配置更改，Netmiko 都能让我们轻松实现自动化。

使用 Netmiko 连接多个设备
在网络管理中，效率至关重要，尤其是在处理多个设备时。Netmiko 功能强大，能够帮助我们轻松无缝地连接和管理多个设备。接下来，我们将探讨如何利用 Netmiko 的强大功能连接多个设备并跨设备执行命令。

首先，我们来设置脚本，使其能够连接到多个设备并检索一些基本信息。我们将使用字典列表来存储每个设备的详细信息，例如其 IP 地址、用户名和密码。

from netmiko import ConnectHandler
import getpass
import json

passwd = getpass.getpass('Please enter the password: ')

# List of device IPs
ip_list = ["172.16.10.11", "172.16.10.12"]

# Create a list of dictionaries for each device
device_list = []

# Populate the device list with device details
for ip in ip_list:
    device = {
        "device_type": "cisco_ios",
        "host": ip,
        "username": "admin",
        "password": passwd,  # Log in password from getpass
        "secret": passwd  # Enable password from getpass
    }
    device_list.append(device)

# Print human-readable device details using JSON formatting
json_formatted = json.dumps(device_list, indent=4)
print(json_formatted)

# Iterate over each device and connect to it
for each_device in device_list:
    connection = ConnectHandler(**each_device)
    connection.enable()
    print(f'Connecting to {each_device["host"]}')
    output = connection.send_command('show run | incl hostname')
    print(output)
    print(f'Closing Connection on {each_device["host"]}')
    connection.disconnect()
在这个脚本中，我们首先提示用户使用getpass库安全地输入密码。然后，我们定义一个设备 IP 地址列表，并遍历每个 IP 地址，创建一个包含设备详细信息的字典列表。

我们使用 Netmiko 的ConnectHandler方法，与列表中的每个设备建立连接。通过执行命令，我们打印出每个设备的主机名，然后优雅地关闭连接。show run | incl hostname

借助此脚本，我们可以高效地连接多个设备并从中检索信息，从而简化网络管理任务。Netmiko 的灵活性和易用性使其成为网络自动化的宝贵工具。

通过利用 Netmiko 的功能，我们可以简化复杂的网络操作，并提高我们在管理网络基础设施方面的整体效率。

使用 Netmiko 简化网络配置
管理多个网络设备的配置可能是一项艰巨的任务，但借助 Netmiko，一切都变得轻松便捷。让我们一起来探讨如何利用 Netmiko 来简化各种设备的配置任务。

向多个设备发送配置命令
使用 Netmiko 的send_config_set()方法，配置多个设备变得轻而易举。请查看以下完整脚本：

from netmiko import ConnectHandler

# Define device details for Cisco devices
devices = [
    {
        'device_type': 'cisco_ios',
        'ip': '172.16.10.11',
        'username': 'admin',
        'password': 'cisco',
        'secret': 'cisco123',
    },
    {
        'device_type': 'cisco_ios',
        'ip': '172.16.10.12',
        'username': 'admin',
        'password': 'cisco',
        'secret': 'cisco123',
    },
]

# Iterate through a list of device dictionaries
for device in devices:
    print(f"Connecting to {device['ip']}...")
    net_connect = ConnectHandler(**device)
    net_connect.enable()

    # Configure the device
    config_commands = ['username admin pri 15 password cisco']
    net_connect.send_config_set(config_commands)
    net_connect.save_config()

    # Display the updated configuration
    output = net_connect.send_command('show running-config | section username')
    print(output)

    print(f'Closing Connection on {device["ip"]}')
    net_connect.disconnect()
遍历设备：循环遍历设备字典列表，每个字典包含设备详细信息。

连接和配置：建立与每个设备的连接，进入启用模式，并使用一组命令对其进行配置。

保存并显示：保存配置更改并显示更新后的配置以供验证。

从文件中更改配置
Netmiko 还允许使用文件中的配置send_config_from_file()方法进行应用。以下是具体操作方法：

from netmiko import ConnectHandler

# Define device details for a Cisco device
device = {
    'device_type': 'cisco_ios',
    'ip': '172.16.10.11',
    'username': 'admin',
    'password': 'cisco',
    'secret': 'cisco123',
}

file = "config_file.cfg"

# Use a context manager to establish a connection to the device
with ConnectHandler(**device) as net_connect:
    output = net_connect.send_config_from_file(file)
    output += net_connect.save_config()

print(output)
建立连接：定义设备详细信息并使用上下文管理器连接到设备。

应用配置：将指定文件中的配置应用到设备并保存更改。

打印输出：打印任何输出或错误消息以供参考。

异常处理
在处理网络设备时，异常处理至关重要。Netmiko 提供了异常类来处理常见问题，例如超时和身份验证错误。以下是如何在脚本中处理异常的方法：

from netmiko import ConnectHandler
from netmiko.ssh_exception import NetmikoTimeoutException, NetmikoAuthenticationException

# Define device details for Cisco devices with potential authentication errors
devices = [
    {
        'device_type': 'cisco_ios',
        'ip': '172.16.10.11',
        'username': 'admin',
        'password': 'cisco123',  # Wrong Password
    },
    {
        'device_type': 'cisco_ios',
        'ip': '172.16.10.12',  # Wrong IP Address
        'username': 'admin',
        'password': 'cisco',
    }
]

# Attempt to establish a connection to each device and execute a show command
for device in devices:
    try:
        net_connect = ConnectHandler(**device)
        output = net_connect.send_command("show ip int brief")
        print(output)
    except NetmikoTimeoutException:
        print(f"Device {device['ip']} not reachable")
    except NetmikoAuthenticationException:
        print(f"Authentication failed for {device['ip']}")
处理异常：优雅地处理超时和身份验证异常，并打印相应的消息以便进行故障排除。

备份设备配置
对于网络工程师来说，自动化设备配置备份至关重要。Netmiko 简化了这一过程：

from netmiko import ConnectHandler
from datetime import datetime

# Define device details for Cisco devices
devices = [
    {
        "host": "172.16.10.11",
        "username": "admin",
        "password": "cisco",
        "device_type": "cisco_ios",
    },
    {
        "host": "172.16.10.12",
        "username": "admin",
        "password": "cisco",
        "device_type": "cisco_ios",
    }
]

# Get current timestamp
time_stamp = datetime.now().strftime("%d-%b-%Y")

# Retrieve the running configuration of each device and save it to a file with a timestamp
for device in devices:
    net_connect = ConnectHandler(**device)
    print(f"Initiating running config backup for {device['host']}...")
    sh_run = net_connect.send_command('show run')

    with open(f"{device['host']}_{time_stamp}.cfg", 'w') as f:
        f.write(sh_run)
        print("Backup saved")

print("Finished backup process.")
备份配置：检索每个设备的运行配置，并将其保存到带有时间戳的文件中，以便存档。
